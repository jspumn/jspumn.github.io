GitHub 私有雲端同步

每新增或刪除一筆記帳，會嘗試在你的私人 GitHub Repository 建立一次存檔（commit）。其他裝置連線後可以讀到相同紀錄。請先在 GitHub 建立一個 Private repository，例如 jspumn/couple-ledger-data。

Token 僅需指定資料儲存庫的 Contents: Read and write 權限。只暫存於這個分頁工作階段，不寫進 GitHub 程式碼或記帳資料；關閉後可能需要重新輸入。請勿給整個帳號的廣泛權限。

尚未連接 GitHub；記帳仍會儲存在本機。

安全提醒：GitHub Pages 仍是公開網頁，但你的記帳資料必須放在不同的 Private repository。若離線，變更會暫存在本機並在重新連線後嘗試上傳。多裝置同時修改時會重新讀取最新版以減少覆寫風險。

資料備份與還原

未啟用 GitHub 同步時，資料只保存在這台裝置。啟用後，每筆異動會寫入你指定的私人 GitHub 儲存庫。

即使加入主畫面，Safari 清除網站資料、使用無痕模式或更換手機，仍可能導致紀錄遺失。請定期下載 JSON 備份並存入 iCloud Drive。
